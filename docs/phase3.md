# Swarm Coder: Phase 3 - Containerized Validation & Sandboxing

This document explores the feasibility and implementation strategy for running generated code within a containerized environment during the Review Phase.

## 1. Objective
To provide a secure, isolated, and reproducible environment where the `Reviewer Agent` can execute and verify the code generated by `Coder Agents` without risk to the host system.

## 2. Feasibility Analysis
*   **Technical Readiness:** High. The project's Python-based architecture is easily containerized using standard `python:slim` images.
*   **Tooling:** Integration can be achieved via the Docker SDK for Python or CLI-based interaction through a specialized `DockerTool`.
*   **Compatibility:** Most generated tasks (scripts, APIs, CLI tools) can be validated in a Linux-based container environment.

## 3. Proposed Architecture
1.  **Validation Image:** A pre-configured Docker image containing the project's base dependencies (`google-adk`, `pydantic`, etc.).
2.  **Execution Sandbox:**
    *   Code is mounted into the container via volumes.
    *   Environment variables (like API keys) are passed securely.
    *   Networking is configured to allow communication with local services (e.g., Ollama) if necessary.
3.  **Feedback Loop:**
    *   `stdout` and `stderr` are captured and returned to the `Reviewer Agent`.
    *   Exit codes determine the success/failure of the validation step.

## 4. Key Benefits
*   **Security:** Prevents malicious or accidental system-level changes on the host.
*   **Runtime Verification:** Goes beyond syntax checking to verify logic and integration.
*   **Clean Room Testing:** Ensures all dependencies are correctly specified in `requirements.txt` or `pyproject.toml`.

## 5. Implementation Roadmap
1.  **Infrastructure:** Create a base `Dockerfile.validation` and a `DockerTool`.
2.  **Integration:** Update `src/swarm_coder/cli/phases.py` to trigger container runs during the review phase.
3.  **Reporting:** Format container logs into concise feedback for the agents to facilitate self-healing.
